# ADR 0003：PostgreSQL、Prisma 与私有对象存储

- 状态：已接受
- 日期：2026-08-04

## 背景

学习记录、素材版本、插槽绑定、发布快照和同步操作需要事务与引用完整性；图片、音频、视频和 PDF 不适合存入关系数据库。

## 决策

结构化数据使用 PostgreSQL，通过 Prisma 管理 schema 和迁移。家庭文件存入私有 S3 兼容对象存储，数据库只保存对象引用、校验值、版本和发布状态。本地开发使用 MinIO。

## 结果

结构化记录与大文件采用不同生命周期；实现必须同时维护数据库引用和对象访问权限，且本地容器卷不能替代正式备份。
